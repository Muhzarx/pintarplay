# ✦ PintarPlay — Belajar Jadi Seru

PintarPlay adalah website permainan edukasi berbahasa Indonesia. Pengunjung bisa belajar sambil bermain melalui kuis pengetahuan, tantangan matematika, tebak kata, dan teka-teki logika.

🌐 **[Buka PintarPlay](https://USERNAME.github.io/NAMA-REPOSITORY/)**

> Ganti `USERNAME` dan `NAMA-REPOSITORY` pada tautan di atas setelah mengunggah proyek ke GitHub.

## 🎮 Permainan

- **Kuis Pengetahuan** — 10 pertanyaan tentang sains, dunia, sejarah, dan Indonesia.
- **Matematika Kilat** — jawab soal hitung sebanyak mungkin dalam 60 detik.
- **Tebak Kata** — susun huruf berdasarkan petunjuk.
- **Asah Logika** — pecahkan pola angka dan teka-teki.

## ✨ Fitur

- Bahasa Indonesia.
- Tampilan responsif untuk desktop dan ponsel.
- Sistem XP dan statistik permainan.
- Progres tersimpan secara lokal di browser (`localStorage`).
- Tidak perlu akun, instalasi, atau backend.
- Bisa di-host gratis menggunakan GitHub Pages.

## 🚀 Cara memasang di GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke folder utama repository.
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan memberikan alamat website.

Contoh alamat:

`https://username.github.io/nama-repository/`

Untuk repository khusus `username.github.io`, alamatnya menjadi:

`https://username.github.io/`

## 💻 Menjalankan di komputer

Cukup buka file `index.html` menggunakan browser. Tidak ada proses instalasi atau build.

## 🔒 Privasi

PintarPlay tidak meminta nama, email, atau data pribadi. Statistik permainan hanya disimpan di penyimpanan lokal browser pengunjung. Menghapus data situs/browser dapat menghapus progres tersebut.
