# ✦ PintarPlay — Belajar Jadi Seru

PintarPlay adalah website permainan edukasi berbahasa Indonesia. Belajar pengetahuan umum, matematika, kosakata, dan logika lewat permainan singkat yang seru.

🌐 **[BUKA WEBSITE PINTARPLAY](https://muhzarx.github.io/pintarplay/)**

📦 **[Lihat repository GitHub](https://github.com/Muhzarx/pintarplay)**

> Jika website belum tampil, aktifkan GitHub Pages melalui **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**. Setelah proses publikasi selesai, buka tautan website di atas.

## 🎮 Permainan

- **Kuis Pengetahuan** — 10 pertanyaan tentang sains, dunia, sejarah, dan Indonesia.
- **Matematika Kilat** — jawab soal hitung sebanyak mungkin dalam 60 detik.
- **Tebak Kata** — susun huruf berdasarkan petunjuk.
- **Asah Logika** — pecahkan pola angka dan teka-teki.

## ✨ Fitur

- Bahasa Indonesia.
- Tampilan responsif untuk desktop dan ponsel.
- Sistem XP dan statistik permainan.
- Progres tersimpan secara lokal di browser (`localStorage`).
- Tidak perlu akun, instalasi, atau backend.
- Gratis digunakan dan dapat di-host melalui GitHub Pages.

## 🚀 Menjalankan website

Website ini sudah disiapkan untuk repository:

`https://github.com/Muhzarx/pintarplay`

Untuk memastikan GitHub Pages aktif:

1. Buka tab **Settings** pada repository.
2. Pilih menu **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`.
5. Klik **Save**, lalu tunggu proses deployment selesai.

Alamat website:

**https://muhzarx.github.io/pintarplay/**

## 💻 Menjalankan di komputer

Unduh atau clone repository, lalu buka `index.html` menggunakan browser. Tidak ada proses instalasi atau build.

## 🔒 Privasi

PintarPlay tidak meminta nama, email, atau data pribadi. Statistik permainan hanya disimpan di penyimpanan lokal browser pengunjung. Menghapus data situs/browser dapat menghapus progres tersebut.
